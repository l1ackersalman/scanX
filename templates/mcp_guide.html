MCP Connection Guide

Connect AI agents to ScanX using HTTP/SSE (no SSH required).

Method 3: HTTP/SSE (No SSH Required)

Run MCP over HTTP/SSE using mcp-remote (requires Node.js). No SSH keys needed!

On Your VPS - Run HTTP MCP Server: 
# On your VPS - run HTTP MCP server on port 8001
python manage.py mcp_server_http --port 8001

# Runs on 0.0.0.0:8001, accessible from anywhere
# MCP endpoint: http://your-vps-ip:8001/mcp
Friend's Config (uses mcp-remote): 
{
  "mcpServers": {
    "scanx": {
      "command": "npx",
      "args": ["mcp-remote", "http://your-vps-ip:8001/mcp"]
    }
  }

Requires npm install -g mcp-remote on friend's machine.

Quick Steps for Your Friend
  1. Install Node.js if needed: winget install OpenJS.NodeJS (Windows) / brew install node (macOS) / sudo apt install nodejs npm (Linux)
  2. Install mcp-remote: npm install -g mcp-remote
  3. Add the JSON config above to their AI client (opencode, claude code, Cursor, Continue)
  4. Restart their AI client

Available MCP Tools

Once connected, AI agents can use these tools:

Tool Description Example Prompt
analyze_attack_surface Full attack surface analysis for a domain "Analyze attack surface for eastdelta.edu.bd"
get_technology_exposure Find all subdomains using a specific technology "Find all subdomains using WordPress"
get_organization_scans List all scans for an organization "Show all scans for NASA"
get_scan_details Full scan results (subdomains, HTTP, tech) "Get details for scan UUID..."
search_subdomains Pattern search across subdomains "Find all api.* subdomains"
create_report Generate AI analysis report (saved in Reports) "Generate vulnerability report for scan UUID..."

Available Resources

Read-only data resources accessible via MCP:

  • scanx://organizations — All organizations with types
  • scanx://scans/recent — 20 most recent scans
  • scanx://technologies — All detected technologies

Viewing Generated Reports

All AI-generated reports are stored in the Reports section (accessible from the sidebar):

  • Navigate to Reports in the sidebar
  • Click View to read the full markdown report
  • Click Download to save as .md file
  • Reports include: Summary, Analysis, Structured Findings (JSON)

Troubleshooting

⚠️ Connection Refused

  • Check VPS port 8001 open: ufw allow 8001/tcp
  • Verify server running: curl http://your-vps-ip:8001/mcp
  • Check server logs for errors

⚠️ Tools Not Appearing

  • Restart AI client completely
  • Check MCP server is running
  • Verify config file path is correct
  • Check client logs for errors

⚠️ Reports Not Generating

  • Ensure scan is completed status
  • Check scan has httpx_results
  • Check Django logs for errors
  • Run tests: python manage.py test

⚠️ Security Considerations

  • The MCP server exposes all scan data to connected AI agents
  • For production: Add authentication (API keys), rate limiting, and audit logging
  • Filter sensitive data (internal IPs, credentials) before exposing via MCP
  • Monitor AI agent activity with audit logs
  • Restrict MCP access to authorized users only
